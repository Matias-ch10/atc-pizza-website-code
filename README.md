# atc-pizza-website-code
Code leerjaar vier atc informatica pizza website.

1. maak een html en css file aan in Visual studio code(html=pizza, css=style)
2. maak een folder aan die heet HTML_CCS(bijvoorbeeld)
3. Daar in zet die files(html en css) in een folder(bijvoorbeeld een file maken die hoofdstuk 2 heet)
4. Uiteindelijk als alles gelukt is zie je een balkje in visual studio code op de pagina explore die HTMLCSS heet
5. In die balkje zie je een andere balkje genaamd hoofdstuk 2, en daarin zie je een html coding screen en eentje voor css
6. copy en paste deze code(html in html, en css in css)
7. drag je pizza.html file in google of safari
